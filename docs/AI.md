# AI use

Tourline Prologue is developed with AI coding agents. The maintainer reviews that work before it is merged, and reviews a release before it is published.

Agents do not publish GitHub Releases, and they do not decide that a measurement is true. Numbers in [progress.md](progress.md) are what was measured in that phase. Anything not measured is labelled as a hypothesis there. A later phase can correct an earlier one.

The licence on this repository covers the port's own code, tools and documentation. It does not cover Gran Turismo 5 Prologue, and it is not permission to commit game code, assets, keys or firmware. `scripts/check_no_game_files.py` refuses those files.

Reuse of the port's own MIT-licensed code, including by automated tools, follows [LICENSE](../LICENSE): keep the copyright and permission notice with the code.
